My Morning Door

Chrome extension

Install My Morning Door

My Morning Door is a free Chrome extension for desktop and laptop computers. Once installed, it appears automatically whenever you open a new tab.

Get the Chrome Extension Continue with the web version

How to install

  1. Open Chrome on your desktop or laptop computer.
  2. Go to the My Morning Door page in the Chrome Web Store.
  3. Select Add to Chrome.
  4. Select Add extension when Chrome asks for confirmation.
  5. Open a new tab using the + button.

There is no separate app to open. My Morning Door becomes your Chrome New Tab page.

Using a phone or tablet?

No need to install anything. The web version runs right in your browser. The Chrome extension is for computers only, so you can add it later on a computer with Chrome or a Chromebook.
